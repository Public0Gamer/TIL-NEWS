# TODAY INDIA LIVE NEWS (कानपुर) - Web Portal & CMS

**TODAY INDIA LIVE NEWS** कानपुर एवं उत्तर प्रदेश का एक आधुनिक, सुपरफास्ट, मोबाइल व डेस्कटॉप रिस्पॉन्सिव न्यूज़ चैनल वेब पोर्टल है। यह प्रोजेक्ट विशेष रूप से **GitHub Pages** पर 100% लाइव चलने के लिए तैयार किया गया है ताकि आप तुरंत अपने क्लाइंट को लाइव डेमो लिंक भेज सकें।

## 🌟 मुख्य विशेषताएं (Key Features)

1. **प्रीमियम ब्रॉडकास्ट थीम (Clean Light Theme)**:
   - डार्क नहीं, बल्कि स्वच्छ सफ़ेद व समाचार-रेड (`#dc2626`) और नेवी ब्लू एक्सेंट के साथ।
   - गूगल फ़ॉन्ट्स (`Mukta` + `Poppins`) - मोबाइल स्क्रीन पर हिंदी पढ़ने में अत्यंत सुगम।

2. **मोबाइल एवं कंप्यूटर दोनों के लिए 100% रिस्पॉन्सिव**:
   - स्मार्टफोन, टैबलेट और डेस्कटॉप सभी स्क्रीन साइज पर सटीक डिस्प्ले।
   - मोबाइल पर हॉरिजॉन्टल स्वाइप मेनू और साइड नेविगेशन ड्रॉवर।

3. **कानपुर विशेष कवरेज ("हमारा कानपुर")**:
   - कल्याणपुर, गोविंद नगर, किदवई नगर, सिविल लाइंस, बिठूर, गंगा बैराज आदि के स्थानीय समाचार।
   - चकरपुर गल्ला मंडी व नयागंज सर्राफा समिति लाइव भाव (गेहूं, दाल, सोना-चांदी)।

4. **लाइव टीवी एवं वीडियो बुलेटिन**:
   - 24x7 लाइव प्रसारण हेतु फ्लोटिंग प्लेयर एवं मॉडर्न टीवी मॉडल।

5. **लाल पट्टी (Breaking News Ticker)**:
   - रियल-टाइम फ्लैश अलर्ट्स जो बिना पेज रिफ्रेश किए चलते हैं।

6. **पाठक अनुकूल सुविधाएं (Article Page)**:
   - **WhatsApp 1-टैप शेयरिंग**: खबर की हेडलाइन के साथ तुरंत शेयर।
   - **फ़ॉन्ट साइज कंट्रोल (A- / A / A+)**: बुजुर्गों व मोबाइल पाठकों के लिए बड़े अक्षर।
   - **खबर सुनें (Voice AI Reader)**: ऑडियो में खबर सुनने की सुविधा।
   - **कमेंट सेक्शन**: पाठक अपनी राय तुरंत दर्ज कर सकते हैं।

7. **नागरिक रिपोर्टर ("खबर भेजें")**:
   - कानपुर के आम नागरिक और स्ट्रिंगर फोटो व विवरण के साथ ग्राउंड रिपोर्ट भेज सकते हैं।

8. **संपादकीय डेस्क व न्यूज़ रूम CMS (`admin.html`)**:
   - 1-क्लिक में नई खबर प्रकाशित करने की सुविधा।
   - ब्रेकिंग न्यूज़ टिकर को लाइव अपडेट करने का विकल्प।
   - नागरिकों द्वारा भेजी गई खबरों को अप्रूव करके सीधे वेबसाइट पर छापने की सुविधा।

## 🚀 GitHub Pages पर लाइव करने का आसान तरीका (2 मिनट में)

इस पूरे फोल्डर को अपने GitHub पर पुश करें और क्लाइंट को लाइव लिंक भेजें:

### Step 1: Git Repository शुरू करें
```bash
cd C:\Users\at781\.gemini\antigravity\scratch\todayindialivenews
git init
git add .
git commit -m "Initial release of TODAYINDIALIVENEWS portal"
```

### Step 2: GitHub पर नया Repo बनाकर Push करें
GitHub पर जाकर नया रिपॉजिटरी बनाएं (उदा. `todayindialivenews`), फिर:
```bash
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/todayindialivenews.git
git push -u origin main
```

### Step 3: GitHub Pages ऑन करें
1. GitHub Repository के **Settings** में जाएं।
2. बायीं तरफ **Pages** पर क्लिक करें।
3. **Branch** में `main` और folder में `/ (root)` चुनकर **Save** दबाएं।
4. 1 मिनट में आपकी वेबसाइट लाइव हो जाएगी:
   👉 `https://<YOUR_USERNAME>.github.io/todayindialivenews/`

अब यह लिंक आप सीधे अपने क्लाइंट को WhatsApp या ईमेल पर भेज सकते हैं!
